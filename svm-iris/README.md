# SVM & Regression on Iris

- `src/svm_classification.py` — SVM (RBF kernel, one-vs-all) on Iris;
  saves a confusion matrix and a PCA 2D projection to `outputs/`.
- `src/linear_regression.py` — linear regression predicting petal length
  from the other Iris features.
- `archive/` — the original graded homework submission (`.zip`) and its
  PDF report, kept for reference.

## Run

```bash
python src/svm_classification.py
python src/linear_regression.py
```
