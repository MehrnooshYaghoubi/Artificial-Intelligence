# Artificial Intelligence

Course projects covering classic search, local-search metaheuristics, and
supervised learning.

| Project | Topic |
|---|---|
| [`eight-puzzle/`](eight-puzzle/) | BFS/DFS/A\* search, plus a contextual-bandit (UCB) tie-breaking variant of A\* |
| [`tsp/`](tsp/) | Traveling Salesman Problem via 7 algorithms (backtracking, CSP, hill climbing, simulated annealing, genetic, ...) |
| [`svm-iris/`](svm-iris/) | SVM classification and linear regression on the Iris dataset |
| [`svm-kernel-comparison/`](svm-kernel-comparison/) | Linear/polynomial/RBF SVM kernels compared across `make_blobs`/`make_circles`/`make_moons` |

Each project folder has its own `README.md` with setup/run instructions and
is self-contained: `src/` for code, `data/` for inputs (where applicable),
and `outputs/` for generated plots/reports.
